Status codes

Rows tagged seen are codes Oracle has actually returned in your traffic; everything else here is standard reference. 402 is reserved for future metered access and tagged watch — it's the one to keep an eye on.

1xx — InformationThe request is being processed.
2xx — SuccessThe request worked.
200OKseenRequest worked
202AcceptedseenRequest accepted for processing — Oracle uses this to acknowledge a handshake, no data required
201CreatedSomething was successfully created
204No ContentRequest worked, but nothing is returned
3xx — RedirectionGo somewhere else / use cached information.
301Moved PermanentlyURL has permanently moved
302Found / Temporary RedirectTemporarily redirected
304Not ModifiedBrowser/cache can use its existing copy
4xx — Client/request problemSomething about the request isn't acceptable.
400Bad RequestServer couldn't understand the request
401UnauthorizedAuthentication is required
402Payment RequiredwatchReserved for future metered access — not live yet
403ForbiddenServer understood you, but won't allow access
404Not FoundseenThe requested URL/resource doesn't exist
405Method Not AllowedWrong HTTP method was used
408Request TimeoutServer waited too long
409ConflictRequest conflicts with current state
410GoneResource used to exist but is intentionally gone
429Too Many RequestsseenRate limit exceeded
5xx — Server problemThe server or an upstream service failed.
500Internal Server ErrorseenSomething went wrong on the server
501Not ImplementedServer doesn't support the requested functionality
502Bad GatewayServer received a bad response from another server
503Service UnavailableServer temporarily unavailable
504Gateway TimeoutAnother server didn't respond in time
Any other/unrecognized status code falls back to a neutral marker in the feed.
